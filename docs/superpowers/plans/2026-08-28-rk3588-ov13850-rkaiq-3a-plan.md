# RK3588 OV13850 RKAIQ/3A Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. The user explicitly requested inline autonomous execution without subagents.

**Goal:** Add a private, reproducible RKAIQ 3A runtime for the OV13850 learning pipeline, prove AE/AWB image improvement, and prepare the permanent module-info driver fix without risking the bootable baseline overnight.

**Architecture:** A pinned RK3588 RKAIQ source is cross-built against the current kernel UAPI into a project-private bundle. A narrow LD_PRELOAD module-info compatibility shim enables no-reboot feasibility testing against the currently running built-in learning driver; the permanent driver ioctl patch is built and verified separately, with Image deployment deferred unless a recoverable boot path exists.

**Tech Stack:** Linux V4L2 subdev, Rockchip RKMODULE UAPI, RKAIQ ISP_HW_V30, C/C++11, CMake/Ninja, aarch64 cross GCC, Bash, jq, RKISP NV12 capture, GStreamer/MPP regression.
